# 30-Day Pool Practice

A free, one-page pool practice tracker: 30 daily drills in 5 weeks (fundamentals, cutting, position, kicks/banks/safeties, break and pressure). Players score each drill and the page tracks progress on their own device.

- Plain HTML, CSS and JavaScript in `index.html`. No build step, no accounts, no server.
- Scores are saved in the browser (localStorage) and never leave the device.
- Works on a phone at the table, in light and dark mode.

## Deploy (free)

GitHub Pages: Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
Or connect this repo to Cloudflare Pages with no build command and output directory `/`.

## Notes

- Drill setups are written generally so they work on any table. Have an experienced player review them before they go into a printed book.
